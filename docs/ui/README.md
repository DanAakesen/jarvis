# Jarvis UI references

Start with the [style guide](style-guide.md) for shared controls, colours, type and motion, and [DESIGN.md](../../DESIGN.md) for design decisions. The apps and their tests are the source of truth for implemented behaviour.

Design references are deleted after implementation. Keep them here only while implementation or a specific acceptance decision is pending; record lasting rules in the style guide or DESIGN.md. Keep runtime assets with the app that reads them, and put disposable captures in build artifacts, not Git.
