# Jarvis visual concept prototypes

## Concept A: Precision instrument

Palette intent: deep graphite-navy with calibrated cyan and teal light. Main values: `#050b12`, `#07131d`, `#5de6f2`, `#48f2cd`, `#f6c65b`, `#ff765f`. Typography uses a precise system sans hierarchy with tight optical spacing. Surfaces are dark instrument panes with measured depth, hairline structure and no single-edge accent treatment. Motion uses 160 ms control feedback, 520-620 ms mode transitions, slow orbital rings, faster thinking rings, scanner sweeps for tool calls and waveform bars for speaking. It serves “alive, especially in voice mode” by making Jarvis feel like a responsive control system as the composer orb grows into a state-driven instrument. Accessibility: state is labelled in text, controls are buttons, focus is visible, Escape exits voice, and reduced motion keeps state readable. Trade-off: it is strong and technical, but less warm.

## Concept B: Living aurora

Palette intent: dark atmospheric base with soft aurora light behind translucent work surfaces. Main values: `#07090f`, `#79ffd7`, `#80c7ff`, `#ff9d80`, `#ffcf7b`, `#ff6b78`. Typography uses rounded system roles for a more approachable assistant. Surfaces are layered glass panels with blur and soft highlights while tables remain legible. Motion uses 160 ms feedback, 520-620 ms mode transitions, a 16 s aurora drift, a canvas-drawn organic orb that morphs with simulated audio, and content shimmer during tool updates. It best serves the “alive” brief because the background breathes, the orb feels fluid, and voice mode becomes a distinct environment without losing the work window. Accessibility: explicit labels/descriptions, keyboard buttons, colour paired with text/shape/motion, hidden-tab pause and reduced-motion fallbacks. Trade-off: this direction needs the most performance testing.

## Concept C: Daylight studio

Palette intent: warm daylight surfaces with ink, muted teal and clay accents. Main values: `#f6f0e6`, `#fffaf1`, `#17202a`, `#276d6f`, `#8f5c3d`, `#b04437`. Typography pairs editorial Georgia headings with a neutral system UI body. Surfaces are matte studio cards with soft shadows and low-contrast structure. Motion uses 160 ms controls, 520-620 ms transitions, gentle ink drift, particle motion around the orb and restrained shimmer. It proves a light theme can still feel alive by making voice mode calm and attentive instead of theatrical. Accessibility: ink-first contrast, labelled states, phone voice docking, visible focus, Escape exit and reduced motion. Trade-off: it has less immediate sci-fi impact than A or B.

## Recommendation

I recommend Concept B as the first visual direction to refine. It best matches Dan’s request for a stunning, alive voice experience while preserving the agreed shell, readable windows and honest sample-data labelling. Concept A is the strongest fallback for an operator-console identity; Concept C is a valuable light-theme companion once the core voice identity is chosen.
