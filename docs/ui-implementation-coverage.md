# Jarvis UI implementation coverage

This report maps the confirmed requirements in [`ui.md`](../ui.md) to existing capability/issues and the frontend task rows in [P8](../PLAN.md#p8--jarvis-ui). The wireframes are structural references, not approved styling or working controls. P8-07, P8-10, and P8-13 are implemented offline; remaining P8 tasks are tracked in PLAN.md.

P8-04–P8-13 were allocated after checking `main` and the two open planning PRs, #233 and #234; neither PR contained P8 implementation-task rows at that check. This range is the frontend allocation. P8-13 uses the existing P1-11 Settings API for light/dark preference. Coordinate the companion backend stream for custom/Jarvis-directed theme-variable updates and replace the temporary P8-03 planning dependency with matching implementation-task dependencies before those capabilities start.
