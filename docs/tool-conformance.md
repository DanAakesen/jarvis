# Tool conformance report

Generated by `apps/backend/src/pi/tool-conformance.test.ts`. Do not edit by hand: after adding or changing a tool, regenerate it with

```sh
cd apps/backend && UPDATE_TOOL_CONFORMANCE=1 npx vitest run src/pi/tool-conformance.test.ts
```

The suite composes every production backend module offline (in-memory stores, stubbed services, stub GitHub and Azure MCP servers), then drives the real
PI MCP door (`find_tools` and `call_tool`) for every registered tool. CI fails when a tool breaks the harness contract, cannot be found, or cannot be called cleanly,
and when this file no longer matches the registry.

## How to read it

- **static**: `ok`, or the violated rule. Rules: a harness-safe unique name (1-64 of `A-Za-z0-9_-`, no `___`, no harness-managed name, no `gh_`/`az_` prefix), an informative description (30+ characters, 6+ words, says when to use it, at most 4,000 characters), a schema the harness accepts (object root, no `strict`, no `$ref`/`$schema`, only plain JSON Schema keywords, no cycles), and a size ceiling.
- **discoverable**: the phrase that makes `find_tools` return the tool and where it ranks. `curated` phrases are what Dan says (English and Danish) and must rank in the top 3 of the first search. `derived` phrases come from the tool's own description; the tool must be returned by `find_tools` (the top 3 in full, the next 5 as compact entries that can be called by exact name too).
- **callable**: `ok` (ran against the stubs and answered with a structured result), `refusal` or `failure (typed)` (a write tool answered with a typed, plain-English ToolRefusal/ToolFailure; the note shows the words), `requiresExternal` (cannot run offline: hardware, live credentials or a paid model; it is still run with its dependency down and must fail cleanly), `not advertised` (the legacy confirmation endpoints are HTTP only; the door must treat them as unknown).
- **schema tokens**: characters / 4 of the parameters schema (definition tokens in the notes include name and description). A search that returns a tool pays its definition in every turn. Ceiling 2000; the exceptions below are listed with their reason.
