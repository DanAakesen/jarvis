### Compatibility and verification boundaries

Capability versions 1–4 keep their original source lists. Version 5 adds the
training-target source; existing tool count is unchanged because it extends
`daily_query`, not the catalogue. Daily remains default-off in code. A target
that is not configured is returned as `null` and listed in `missing`; zero stays
a configured value. The target timestamp is the stored update time, not a
Health-feed freshness claim.

The SQL projection and registered-handler regressions use synthetic records.
Local SQL integration requires the repository's isolated loopback SQL Server;
it does not run against production. Neither those tests nor this matrix establish
live owner records, production reachability, source parity, or English voice
tool-registration availability (#1188).
